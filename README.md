## ✨ About The Project

**UIndx** is a modern **Air Quality Index dashboard** designed to make environmental data simple, visual, and easy to understand.

Users can search for a location and view its current air-quality information through a clean and interactive dashboard.

The project focuses on combining **real-time API data** with a modern **UI/UX experience** to provide users with meaningful information about pollution levels.

---

## 🚀 Key Features

* 🔎 **Location Search**
  Search for air-quality information for different locations.

* 🌍 **Air Quality Dashboard**
  View AQI information in a clean and intuitive visual layout.

* 📊 **Live API Data**
  Fetches real-time air-quality information from an external API.

* 🧪 **Pollutant Information**
  Displays information about the dominant pollutant affecting air quality.

* ⚠️ **Pollution Risk**
  Provides a simple visual indication of the current pollution risk.

* 📱 **Responsive Design**
  Works smoothly across desktop, tablet, and mobile devices.

* 🎨 **Modern UI**
  Features a dark, futuristic interface with gradients, cards, and visual indicators.

* ⚡ **Dynamic Content**
  Dashboard content updates dynamically based on the searched location and API response.

* 🔄 **Loading & Error States**
  Handles API loading states and errors to provide a better user experience.

## 🔄 How It Works

```text
User enters a location
        ↓
JavaScript handles the search
        ↓
API request is sent
        ↓
API returns JSON data
        ↓
Data is processed
        ↓
Dashboard updates dynamically
        ↓
User sees current AQI information
```
